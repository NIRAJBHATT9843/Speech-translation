# Nepali to English Machine Translation

This project implements a Transformer-based model for translating
Nepali sentences into English.

## Features
- Transformer model built from scratch
- Greedy decoding
- BLEU score evaluation
- Text-to-speech output

## How to Run

1. Activate environment
   source venv/bin/activate

2. Train model
   python -m src.train

3. Translate sentence
   python app.py
